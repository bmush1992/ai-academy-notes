# ai-academy-notes
Корпоративные обучалочки

Здесь будет информация по моему ИИ-корректору. Скорее всего, в какой-то момент репозиторий придется сделать закрытым, но пока так.
Инициатива предполагает большую работу по подготовке промптов, ее высокую итеративность и участие коллег.
Репозиторий станет хранилищем информации для контроля статуса проекта.

_Ждем API для нашего Qwen'a, а пока готовим интерфейс, инструментарий для работы с глоссариями, собираем материалы для тестирования и общаемся с заказчиками на предмет их точки зрения на проблему обсуждения проблем перевода на совещаниях, чтобы подготовить базу для оценки решения._
